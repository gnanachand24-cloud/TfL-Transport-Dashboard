# TfL London Transport Performance Dashboard

## Live Dashboard
🔗 [View on Tableau Public](https://public.tableau.com/app/profile/gnana.bhoopati/viz/TfLLondonTransportPerformanceDashboard/Dashboard1)

## Project Overview
Interactive Tableau Public dashboard analysing Transport for London (TfL)
performance data from 2010 to 2025, covering the London Underground
and all major transport modes.

## Dashboard Visuals
| Visual | Description |
|---|---|
| Underground Journey Trend | Monthly journey volumes over time showing COVID impact and recovery |
| Service Reliability | % of scheduled services operated vs 95% target — by year |
| Lost Customer Hours | Annual delay impact in millions of hours |
| Transport Mode Comparison | Bus, Tube, DLR, Overground journey volumes side by side |

## Key Findings
- Underground journeys crashed by ~95% during COVID lockdowns (2020)
- Service reliability has averaged above 95% target in most recent years
- Bus remains the most heavily used TfL mode by journey volume
- Lost Customer Hours peaked in [your peak year — check your chart] and have since [improved/worsened]
